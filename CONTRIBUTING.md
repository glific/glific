Thanks for your intrest! To start contributing in this repo. 

1. Clone this Repo
2. Setup the project by following the steps in the [readme.md](https://github.com/glific/glific#readme)
3. Pick an issue to work on from this board [bugs/enhancements](https://github.com/orgs/glific/projects/8/views/28)
    - Choose one which is not assigned to anyone else
    - Would be good to chose one which is a higher priority (P1/P2)
5. Whenever you create a PR, make sure:
     - All CI checks are passing 
     - All CodeRabbit review comments have been properly addressed before requesting a review.
6. You can reach out to us on our [discord server](https://discord.com/channels/717975833226248303/1558079720975900713) in case of any queston/suggestions.
